# D&D 5e Character Creation

Generatore di schede personaggio per Dungeons & Dragons 5a edizione (regole del Manuale del Giocatore 2014).

Stato: in costruzione. Struttura del progetto:

- `dnd5e/rules/` dati di regole in YAML (caratteristiche, razze, classi, background, equipaggiamento).
- `templates/official/` PDF ufficiale Wizards of the Coast (distribuito gratuitamente per uso personale) e mappa delle coordinate dei campi.
- `characters/` un file YAML per personaggio con il suo ritratto.
- `output/` le schede PDF generate.

Il motore di calcolo, il renderer PDF e la CLI arrivano nel prossimo commit.
