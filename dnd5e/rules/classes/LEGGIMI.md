Una classe per file (chiave in cima = chiave della classe). Il motore li unisce in rules['classes'].
Classi del Manuale del Giocatore (PHB 2014). Guerriero, Druido e Mago sono completi (privilegi 1-20 + sottoclassi).
Le altre classi hanno i dati strutturali (dado vita, TS, competenze, abilità) e i privilegi dei primi livelli.
features: per livello, lista di {name, short, text}. Le voci con "level" dentro un archetipo seguono lo stesso schema.
name_f: nome al femminile (classe, sottoclasse o privilegio con nome di genere).
kid: testo semplicissimo per le bambine (seconda persona, cosa significa in gioco). Segnaposto: {cd} {att} {mod}
     {livello} {soffio_cd} {soffio_danni} {soffio_tipo} {soffio_area} {soffio_ts} {forma_ore}.
kid_hide: true = voce di sola contabilità (già riportata altrove sulla scheda), nascosta nella versione semplice.
grants_cantrip: trucchetto dato gratis dal privilegio (non conta nei trucchetti conosciuti).
